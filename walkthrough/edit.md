# Edit in the tree or the form

Double-click a value or a key to change it, then press Enter. Escape keeps the old text.

The selected row has a type menu and buttons to add an entry inside, duplicate the row or delete it. Drag a row to move it to another place in the same object or array.

The form on the right lists the fields of the selected object: type in a box, tick a checkbox, or follow a link into a nested object.
