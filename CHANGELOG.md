# Changelog

## 0.1.0

- First release.
- Open .json, .jsonc and .json5 files in a tree with a form beside it. The text editor stays the default.
- Edit values and keys in place, add, duplicate, delete, drag to reorder and change a value's type.
- A change replaces only the edited text, so comments, key order and formatting stay; undo, redo and save are
  VS Code's own.
- Search keys and values, jump to a value's line in the text, big numbers kept exactly, theme colors.
- Zovo Pro tools, one free try each: Table mode, Bulk edit by JSONPath, and Compare and merge.
